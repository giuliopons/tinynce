# Configuration and dependencies

## Runtime config

Config in `pons-settings.php` (gitignored — never commit it):
```php
define('DB_HOST', '...');
define('DB_USER', '...');
define('DB_PASS', '...');
define('DB_NAME', '...');
```
Template for new installs: `pons-settings-install.php`.

## Composer

**Composer is actually used in this repo**, despite earlier versions of this documentation
claiming otherwise. `src/_include/config.php` unconditionally does
`require $root . 'src/vendor/autoload.php';`. `src/composer.json` declares:

```json
{
    "require": {
        "phpmailer/phpmailer": "^6.9",
        "altcha-org/altcha": "^1.1"
    }
}
```

- `phpmailer/phpmailer` is used for sending SMTP email (see `mail_utf8()` in `comode.php`
  and the `SMTP_*` constants in `constant_intelliphense.php`).
- `altcha-org/altcha` is present as a dependency but doesn't appear to be referenced yet in
  the core components' PHP code — check the specific project before assuming it's actively
  used (likely an anti-bot captcha planned for public forms, complementing `botfilter.php`).
- `src/composer.json`, `src/composer.lock`, and `src/vendor/` are **gitignored** (see
  `.gitignore`: `src/composer.*`, `src/vendor/*`): they exist on the local/production
  filesystem but aren't tracked in git. Anyone cloning the repo must run `composer install`
  inside `src/` before using the framework.
- Adding new dependencies must be deliberate and surgical — this is a stable production
  system, not a greenfield project.

## Constants from the database

Many constants (`MONEY`, `SMTP_*`, `PAYPAL_*`, `TWILIO_*`, `NUMBERFORMAT`,
`CUSTOM_LOGIN_CLASS`, etc.) are defined at runtime by reading the `frw_vars` table, not in
code. `src/_include/constant_intelliphense.php` redeclares them with a sentinel value
(`"DEFINE_ERROR"`) purely to avoid editor/Intelephense warnings — **this file should be
regenerated by hand if the list of variables managed by `frwvars` changes**; it is not
auto-generated despite the comment at the top of the file implying otherwise.

## Non-Composer assets and libraries

- `src/assets/` (jQuery, TinyMCE, viewer) and `src/lib/` (filemanager, php-zip) are
  gitignored (`src/assets/*`, `src/lib/*`) and must be populated manually for each
  installation — they are managed neither by Composer nor by `copiacore.php`.
